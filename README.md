## 🚀 Cum să urci proiectul pe Vercel (2 metode simple)

### Metoda 1: Direct din Terminal (Cea mai rapidă — sub 1 minut)

Deschide terminalul și rulează:

```bash
cd /Users/riccardo/.gemini/antigravity-ide/scratch/prezentare-daniel
npx vercel
```

1. Când te întreabă `Set up and deploy?`, apasă `Y`.
2. Selectează contul tău Vercel (dacă nu ești autentificat, te va loga automat din browser).
3. Apasă `Enter` la toate setările implicite.
4. În 15 secunde vei primi un link live (de exemplu: `https://prezentare-daniel.vercel.app`) pe care îl poți trimite direct pe WhatsApp lui Daniel!

---

### Metoda 2: Prin GitHub & Vercel Dashboard

1. Creează un repository pe GitHub (ex: `idei-business-daniel`).
2. Fă push la fișierele din acest folder:
   ```bash
   cd /Users/riccardo/.gemini/antigravity-ide/scratch/prezentare-daniel
   git init
   git add .
   git commit -m "Prezentare idei de business pentru Daniel"
   git branch -M main
   # Adaugă remote-ul tău și fă push:
   # git remote add origin https://github.com/USERNAME/REPO.git
   # git push -u origin main
   ```
3. Intră pe [vercel.com/new](https://vercel.com/new), selectează repository-ul și apasă **Deploy**.
